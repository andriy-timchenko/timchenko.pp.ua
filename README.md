# timchenko.pp.ua — Історія України

Просвітницький односторінковий сайт: інтерактивна хронологія з джерелами, порівняння Києва та Москви, відео.

- Увесь текст і джерела: `src/data/history.ts`
- Зображення: `public/images/`
- Локальний запуск: `yarn install && yarn dev`
- Публікація: кожен push у `main` автоматично збирає сайт і оновлює GitHub Pages (`.github/workflows/deploy.yml`).

Попередня версія (Astro) збережена в гілці `old-astro`.
